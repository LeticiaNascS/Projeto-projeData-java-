# Projeto-projeData-java 


Este repositório contém a solução desenvolvida para o teste prático de programação proposto pela empresa **Projedata**, com foco em lógica de programação, orientação a objetos e manipulação de coleções em Java.

## Objetivo

Desenvolver um projeto Java considerando uma lista de funcionários, aplicando conceitos como:

- Herança
- Encapsulamento
- Listas
- Mapas
- Streams
- Formatação de datas e valores
- Ordenação
- Filtros
- Cálculos financeiros
